# 🪞 CodeMirror

CodeMirror is a beginner-friendly Python project that helps me
track my coding problems and mistakes.

## ✨ Features

- Add coding problems
- Store problem topics
- Record mistakes
- View saved problems
- Count mistakes by topic
- Find the weakest topic

## 🛠️ Built With

- Python

## 🚀 Future Improvements

- Save data permanently
- Practice recommendations
- Progress statistics
- SQL database
- Web interface
- AI-based mistake analysis

## 👩‍💻 About

I built CodeMirror while learning Python and problem solving.
This project is part of my journey toward becoming a software engineer.
